# DMIT 中文网：中文界面入口、支付宝付款和洛杉矶/香港/东京套餐怎么选

## 搜索结果里那三类“中文网”，别搞混

搜同一关键词，出现在眼前的通常是三种东西，性质完全不同。

**第一类，官方页面的中文版本。** DMIT 主站是英文界面为主，活动页和部分说明页有中文。如果你的目的只是“看懂某个促销规则”，把活动页切成中文最省事。但注册、下单、账单、工单这一整套流程，界面主体仍是英文。

**第二类，第三方维护的中文资讯站。** 比较典型的是以 `dmithost.net`、`dmitvps.com`、`dmiter.com` 这类域名存在的博客，它们在页面里直接自称“DMIT 中文网”。内容以补货通知、套餐整理、优惠码记录、教程为主，更新频率往往还不错。它们的价值在于“什么时候补货了”这类动态信息；问题在于价格表经常是滞后的，同一个页面里可能并存两三个时期的价格。

**第三类，论坛和 GitHub 上的整理帖。** NodeSeek、全球主机交流、V2EX 上一堆帖子，还有一些专门开仓库做 DMIT 优惠码汇总的账号。信息量大，但时效性极不平均——同一批套餐，你能同时看到 $9.99/月和 $12.98/月两种入门价，原因后面会解释。

## 为什么同一款套餐会出现两个价格

这是搜“DMIT 中文网”时最容易踩的坑，值得单独说清楚。

DMIT 在 2025 年对洛杉矶机房做过平台升级，从 AMD EPYC 9004（资料里写作 AN4）切到 9005（AN5），升级期间的公开清单里，同一档 LAX.Pro.TINY 被标成过 $9.99/月，也被标成过 $12.98/月。差别来自硬件批次和产品代号，不是谁抄错了。资料里还能见到 AN3（EPYC 7003）的洛杉矶清单，标价 $10.9/月，那是更早一段时期的补货批次。

所以看到一个价格，先问它对应的是哪个平台代号。AN3、AN4、AN5 的性能差距是实打实的，2019 年那种“反正都是 AMD”的印象在这儿不适用。

香港和东京机房也有类似的分代问题。香港 Pro 目前以 AS3（EPYC 7003）为主，也出现过 AN5 平台的更高配档位，价格往上抬了一截；东京的 Eyeball 系列（TYO.AS3.EB）已经被官方下架，东京 Pro（TYO.AS3.Pro）一度长期售罄。这些变化在第三方“中文网”上往往更新不及时。

## 三条线路看懂，套餐名就不再是乱码

DMIT 的套餐命名逻辑是“机房 + 线路 + 档位”，比如 LAX.Pro.TINY 就是洛杉矶、Premium、最小档。真正决定体验的是中间那一段。

| 线路代号 | 全称 | 中国大陆优化 | 典型适用 |
| --- | --- | --- | --- |
| Pro | Premium | 三网回程 CN2 GIA，最强 | 电信用户、对延迟敏感的建站场景 |
| EB | Eyeball | 电信/联通走 9929、移动走 CMIN2 | 移动和联通用户，性价比取向 |
| T1 | Tier 1 | 无中国方向优化，国际互联 | 面向海外用户、要大流量大带宽 |
| sPro | Premium Secure | CN2 GIA 叠加 DDoS 防护 | 有防护需求的站点 |

有个细节经常被忽略：T1 系列流量用完后不停机，改成限速继续跑。WEE 档超量后限 50Mbps，往上的档位限 100Mbps 到 1Gbps 不等。对流量波动大的项目，这比“超了就断线”实用得多。

反过来，T1 也有明确的劝退场景。电信用户买香港 T1，到内地的延迟可能比买一台美国机器还难看。它不是“便宜版的 Pro”，它是另一条线路。

## 付款、退款、换 IP：中文用户问得最多的三件事

**付款。** 支付宝和 PayPal 是被资料反复提到的，信用卡也在支持列表里，另有资料提到微信支付。对没有双币卡的人来说，支付宝这条路是能走通的。

**退款。** 公开政策是：新购 3 天内、流量使用不超过 30GB 可以申请全额退款；30 天内按剩余价值退。另外有个容易被忽略的限制——退款主要针对新用户，之前买过的账号不一定适用。

**换 IP。** IP 被封之后，非月付套餐或购买了换 IP 服务的用户，可以每 15 天免费换一次。按月付的老实掏 $5/次。

**客服。** 工单系统可以用中文提交，但实际回复以英文为主，这一点资料里提到过好几次。技术问题写清楚机房、套餐名、报错现象，比写一大段背景更有效。

## 缺货这件事，得接受它是常态

DMIT 不超售，这是它在圈子里口碑的来源，也是套餐常年缺货的原因。每批硬件上架数量有限，卖完就下架，等下批到货再补。

从公开记录看，补货有几个高频时间点：黑五、圣诞元旦、春节、618 这些大促节点，季度末和月末也会小规模放出因退款或到期释放的资源，产品做升级改配时通常也会同步开库存。想第一时间知道，盯官方 Telegram 频道比反复刷第三方博客更靠谱。

所以如果你看到某个具体档位“暂时缺货”，合理动作是：换同系列的相邻档位，或者换个机房。线路类型对了，体验差不了太多。

## 常见问题

**有没有一个专门的中文官网？**
没有。主站支持部分中文页面，但不存在独立的“DMIT 中文网”官方站。自称这个名字的站点基本都是第三方资讯博客。

**香港 T1 能不能当香港优化机用？**
不能。它是国际线路，没有中国方向优化，电信用户晚高峰体验可能明显不如美国 Pro。

**预算有限，只想要一条能稳定跑回国的线路，选哪个？**
先看你是什么宽带。电信优先看 LAX.Pro.TINY 这一档，移动和联通优先看 EB 系列。年付的入门款比月付单价低，但不建议一上来就买最高档。
